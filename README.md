# tiny-learners-media

Final media files for the Tiny Learners kids YouTube channel.

## Folders

episodes/        Full-length 16:9 masters, sorted by topic
  space/           Planets, moon, stars, asteroids, Milky Way
  animals/         Elephants, lions, giraffes, penguins, sharks, bugs, and others
  dinosaurs/       Dinosaur episodes
  earth-and-nature/  Earth, ocean, pyramids, butterflies, bees
  science-and-safety/  Science experiments and fire safety
shorts/          Companion Shorts (9:16)
tiktok/          9:16 copies made for TikTok
compilations/    Binge videos that combine several episodes
thumbnails/      Episode and compilation thumbnails
audio/           voiceover/ and music/ source tracks
scripts/         Episode scripts
coloring-books/  KDP coloring book interiors and covers
archive/         Older versions and replaced files

## Naming

Use lowercase words joined by underscores, plus the video number and a version tag.
Example: giraffe_video8_master.mp4

Keep one final file per episode in episodes/. Move replaced versions to archive/.
